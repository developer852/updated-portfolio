# ✨ Devika Mane - Next-Gen Java Backend Developer Portfolio

An ultra-modern, cyberpunk-clean, and interactive developer portfolio for **Devika Mane** — Java Backend Developer & Software Engineer.

## 🚀 Key Features

- **⚡ Futuristic Boot Preloader**: Animated custom typography loader with simulated JVM 21, Spring Boot kernel, HikariCP pool, and Hibernate ORM boot sequence telemetry.
- **🖥️ Stacked Hero & Live Microservice IDE**: High-impact headline with dynamic typing, live metrics ticker, and an interactive `@RestController` Spring Boot simulator with instant response mock testing.
- **🧱 Interactive Bento Grid**: Live mock API sandbox, interactive CLI terminal with command evaluation (`help`, `skills`, `projects`, `ai <query>`, `curl`, `theme`), and system architecture statistics.
- **📂 Selected Projects Showcase**: Detailed production breakdowns for Banking Application (Spring Boot + MySQL), Exam Management System (Core Java + JDBC), and Employee Management System (PostgreSQL + Hibernate ORM), each with live interactive modal simulators.
- **🎙️ Devika AI Voice Copilot (v2.6)**: Built-in verbal AI assistant with female voice synthesis (`SpeechSynthesis`), voice microphone input (`SpeechRecognition`), dynamic action buttons, and query chips.
- **🎨 Dynamic Cyberpunk Theme Presets**: Instant accent switching (`Cyan`, `Purple`, `Emerald`, `Amber`) via the floating dock or terminal.
- **📱 macOS-Style Floating Dock**: Glassmorphic quick navigation dock with haptic audio sound effects synthesized via Web Audio API.
- **⌘K Command Palette**: Fast keyboard navigation modal with live search filtering.
- **📱 100% Fully Responsive & Smooth Scrolling**: Optimized with GPU layer acceleration and zero-reflow scrollspy for 60/120 FPS performance on mobile, tablet, laptop, and desktop.

## 💻 Local Setup & Running

1. **Clone the repository**:
   ```bash
   git clone https://github.com/developer852/devika-portfolio.git
   cd devika-portfolio
   ```

2. **Open directly in browser**:
   - Double click `index.html` to open it in any browser, or use VS Code Live Server.

3. **Or run with Node.js**:
   ```bash
   node server.js
   ```
   Open `http://localhost:3000` in your browser.

---

## 🌐 Deploy to GitHub Pages

1. Create a new repository on GitHub named `devika-portfolio` (or `<your-username>.github.io`).
2. Run the following in your terminal:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Devika Mane Next-Gen Portfolio"
   git branch -M main
   git remote add origin https://github.com/developer852/devika-portfolio.git
   git push -u origin main
   ```
3. Go to **Repository Settings** &rarr; **Pages** &rarr; Select `main` branch `/ (root)` &rarr; Click **Save**.
4. Your website will be live in ~1 minute at `https://developer852.github.io/devika-portfolio/`!
